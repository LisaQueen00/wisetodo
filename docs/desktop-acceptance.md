# Phase 6 桌面能力验收

启动：在项目根目录执行 `pnpm.cmd tauri dev`。不需要模型调用。
保留原生标题栏拖动与边缘缩放。首次尺寸为工作区宽度 1/3、高度 3/5，受现有最小 720×520 限制；以后恢复位置尺寸。默认置顶，可用图钉切换并保存。

## 动作清单

1. 覆盖其他窗口，检查默认置顶；取消/恢复图钉，退出重开检查记忆。
2. 拖动窗口、缩放，右上角关闭：应隐藏到托盘，不退出。托盘菜单“显示”恢复窗口；“退出”才停止后台。
3. 最小化后再次启动同一应用，应唤起原窗口，不多出第二实例。正常启动不恢复隐藏/最小化状态。
4. 在空列表新增 Todo、编辑已有 Todo，检查定位、展开和持续 10 秒的柔和边框闪烁；系统启用减少动态效果时改为静态描边。首次历史加载不闪烁。
5. 用户主动勾选开机启动后才注册；取消应撤销。开机启动带 `--background` 进入托盘；托盘创建失败或检测到异常退出时保持可见。
6. 正常退出再启动不显示异常提示。异常中断后下次启动提示“确认重启/继续使用”，不自动重试模型、不自动重启。测试异常中断会打断未完成任务，请仅在测试数据上操作。
7. 托盘不可用时，界面说明关闭将退出，不留下无法唤起的隐藏窗口。

不要为了验收自动修改用户开机启动项。开发版注册的是开发路径，发布后需检查安装包的路径与系统权限。参考 [Tauri 托盘](https://v2.tauri.app/learn/system-tray/)、[窗口状态](https://v2.tauri.app/plugin/window-state/)、[开机启动](https://v2.tauri.app/plugin/autostart/)。

## 退出与限制

正常退出发送 stdin EOF，让 Python 取消 Run 并清理解析/MCP 子进程；500 ms 后仍未退出则强停 Python。应用崩溃、系统强杀以及不配合清理的外部工具，不能保证所有后代进程都被回收，进程树强制隔离仍需后续加固。异常标记仅表示未走完正常退出，不等同于断言数据库损坏。

置顶设置与异常标记位于应用数据目录，窗口尺寸状态由 window-state 插件保存在配置目录；不保存模型密钥。正常关闭进入后台时，已在执行的任务继续运行，但不会启动新模型任务。

当前验证范围：Windows 编译、Rust/前端自动化、Python 延迟加载及运行回归，用户已操作关闭到托盘并完成进程树空闲采样。系统登录启动、显示器切换、macOS/Linux 桌面及上述后续内存场景仍需设备验收，尚不能宣称三平台 Phase 6 验收通过。
