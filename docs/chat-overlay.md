# 窄版 Todo 与 Chat 覆盖层

默认 400 逻辑像素宽，最小 360。Chat 在固定窗口内从右侧覆盖 Todo 内容区，顶部切换按钮始终可见；不创建第二个窗口、不自动加宽、不因失焦收起。每次启动默认展示 Todo。

两个工作区保持挂载，只切换可见性与 inert，保留草稿、会话和 Todo 局部状态/滚动。关闭 Chat 不取消运行；按钮提示运行中。隐藏 Chat 停止文件拖放监听，执行监听继续保留。Escape 收起并将焦点放回切换按钮；减少动画偏好下关闭滑动动画。

桌面选项折叠在公共顶部。置顶、托盘、窗口尺寸/位置保存沿用现有实现。升级首次用应用数据目录中的 overlay-layout-v1.marker 标记完成窄版迁移；迁移会重置窗口大小并居中一次，不改 Todo、聊天或模型配置。之后不再强制宽度，尊重用户拖动调整。

本次聚焦用户确认的形态；尚未实现透明背景或透明度设置，未改变主题色与鼠标穿透策略。真实 Windows WebView 的动画、窄宽度表单布局、后台执行切换与托盘恢复仍需人工验收。
