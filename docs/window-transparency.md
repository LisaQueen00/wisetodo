# 8.2 背景透明度

桌面选项提供背景不透明度，60–100%，默认 85%。100% 恢复不透明，数值越低越透。偏好保存在本机 WebView localStorage，不进入模型配置或聊天上下文；损坏/不可读值回退 85%，写失败保留当前效果并提示无法留存。

Windows 专用 tauri.windows.conf.json 开启原生透明并设置 WebView 背景透明。平台配置中的窗口数组完整覆盖主配置，因此 Rust 测试确保除透明属性外与主配置一致。依据 [Tauri 平台配置与窗口透明选项](https://v2.tauri.app/reference/config/#windowconfig)。其他平台没有启用新原生透明选项，不声称跨平台效果一致。

CSS 只改变主面板背景 alpha，卡片采用轻量背景色，不设置整个窗口 opacity。沿用已有完成态文字/颜色与透明度规则；没有新增文字整体淡化。Chat 使用同一背景，打开时 Todo 视觉层隐藏但保持挂载，避免文字叠影。没有鼠标穿透、失焦淡化或模糊特效；系统标题栏依然由系统绘制，可能不透明。

验收：先在编辑器、浏览器深浅背景上分别尝试 60/85/100%；检查滑杆/文字/输入/拖动、Chat 开关和完成态。退出后重开检查留存，托盘恢复检查可操作性。背景透明不减少窗口实际鼠标遮挡，点击仍由 WiseTodo 接收。无付费模型调用；性能与真实桌面合成效果不能由 jsdom 测试代替。
