# 内置能力与网页读取（Phase 8.4 / 8.5）

干净用户目录默认启用 `parse_pdf`、`read_github_project`、`search_projects`、`read_url`。缺少用户 `skills/` 时回退到随包三个 Skill；源码版读取仓库示例，冻结版读取包内 `builtin_skills/`。已有目录完整替代默认 Skill（空目录可禁用），已有 Tool 配置完整替代默认工具（空列表可禁用）。不写回、覆盖或迁移用户配置；每个新 Run 重读，旧 Run 快照不变。不启用未知 MCP 服务。

## 网页支持范围

首版只读取公开静态 HTTP(S) HTML/XHTML/纯文本页面，输出最终 URL、标题、正文、最多 20 个链接和裁剪标记。不是浏览器，不执行 JavaScript，不处理登录、验证码，不保证复杂页面正文提取质量；脚本/样式等内容跳过。正文不足仍需澄清，不编造已读取事实。

- GET、标准端口、禁止凭据 URL；每一跳重新解析 DNS，拒绝非公网地址，实际连接固定到已检查 IP，保留 Host/SNI 与 TLS 证书验证。
- 禁用环境代理、自动跳转和跨跳 Cookie；最多 4 次请求，整体 20 秒、单请求 8 秒超时。
- 仅允许列出的文本类型；拒绝压缩响应，流式读取最多 1 MiB；正文最多 12,000 字符，链接不会自动继续抓取。
- 序列化后的单次结果最多 15,000 字符；超出时先减少链接，再缩短正文，避免整份资料因模型工具预算被省略。
- 页面内容始终是不可信资料；提示词禁止网页指令覆盖系统规则，但不声称提示词能彻底解决提示注入。
- 工具执行记录区分未启用、网络/超时、限流、安全阻止及不支持页面，使用固定提示，不显示远端异常正文。资料不足通过模型澄清呈现，不能与读取失败混同。

连接固定 IP 使用 [HTTPX SNI 扩展](https://www.python-httpx.org/advanced/extensions/)。网页读取不等同于网页搜索，也不实现“搜索后继续读取”的多步 Agent 协议；这仍是 8.6 的任务。

## 验收

```powershell
.\.venv\Scripts\python.exe -m pytest backend/tests/test_web_reader.py backend/tests/test_builtin_skills.py backend/tests/test_default_tools.py -q
```

测试用模拟 DNS/HTTP、Provider 和临时目录，不调用付费模型。覆盖公网连接固定、内部/链路本地/IPv6 地址拒绝、跳转重验、响应类型和体积、脚本过滤、限流、网络错误、取消、配置禁用、Run 快照和重开。

安装新版前从托盘彻底退出旧应用。首次体验可给公开 GitHub 仓库根 URL，或公开静态网页并说明规划目标；查看执行记录是否调用读取工具。已有用户 tool-settings.json/skills 目录会继续覆盖默认值：不要为了启用默认值而直接删除个人配置，应先备份再决定保留哪些条目。本项不自动操作用户数据；真实模型业务效果由用户验收。
